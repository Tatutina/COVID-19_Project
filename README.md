# COVID-19_Project

Анализ медицинского датасета COVID-19 Recovery Dataset с использованием кластеризации пациентов и анализа выживаемости Kaplan-Meier. Проект демонстрирует полный пайплайн: от предобработки данных до интерпретации результатов.

Цели:

Выделить группы пациентов с похожими характеристиками выздоровления

Оценить различия в времени выздоровления между кластерами

Провести статистический анализ выживаемости

📊 Датасет
Источник: Kaggle COVID-19 Recovery Dataset

Размер: ~10,000+ записей пациентов

Признаки: демография, симптомы, лечение, исходы

Задача: неконтролируемая кластеризация + анализ выживаемости
